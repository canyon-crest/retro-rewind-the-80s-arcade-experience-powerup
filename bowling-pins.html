Top-Down Bowling Pins

32×32 sprites · 24 fall angles (every 15°) · 8 frames each · physics-ready API

Idle State

Angle Compass — 24 Directions × Final Frame

Each pin shows the fully fallen frame (F7) in its angle's fall direction.

Frame Strip — Pick an Angle

90° DIR (1.00, 0.00)
Each frame is its own 32×32 canvas. F0 upright → F7 fully fallen.

Full Matrix — All 24 × 8 = 192 Frames

Scrollable. Rows = angle (0°–345°), columns = frame (F0–F7).

Interactive — Click to Strike

click anywhere · pin falls AWAY from click
double-click to reset
Each pin runs independently. The pin computes the impact vector, snaps to the nearest 15°, and plays that angle's animation.

Physics API — window.BowlingPins

// All sprite data is precomputed and exposed:
BowlingPins.ANGLE_STEP    // 15
BowlingPins.ANGLE_COUNT   // 24
BowlingPins.FRAME_COUNT   // 8
BowlingPins.FALL_DURATION // 420 (ms, suggested)

// Per-angle metadata + sprites:
BowlingPins.ANGLES[i] = {
  index:    0..23,
  degrees:  0, 15, 30, ... 345,    // clockwise from NORTH
  radians:  0 .. ~6.02,
  direction:{ x, y },              // unit vector in screen space (+y = down)
  frames:   [HTMLCanvasElement x 8] // F0 = upright, F7 = fallen
}

// Utility functions:
BowlingPins.angleFromVector(dx, dy)   // → degrees [0, 360)
BowlingPins.nearestAngleIndex(deg)    // → 0..23
BowlingPins.getIdleSprite()           // → HTMLCanvasElement (F0)

// Pin factory — drop one into your game:
const pin = BowlingPins.createPin();  // { canvas, knock, reset, update, state }
container.appendChild(pin.canvas);

pin.knock(impactDx, impactDy);        // pin will fall AWAY from impact vector
// or: pin.knockAngle(degrees);
// or: pin.knockIndex(0..23);

// In your game loop:
function tick(now) {
  pin.update(now);                    // advances animation
  requestAnimationFrame(tick);
}

pin.reset();                          // back to idle
